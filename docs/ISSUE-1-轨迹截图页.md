## 一、Issue 原文

> 有没有考虑在在轨迹截图页面做个fake的，可以改各个参数和背景跑步图

## 二、需求拆解

一句话里其实有三个独立诉求：

1. **要有"轨迹截图页面"**——当时项目只有一个跑步主页 `pages/index/index`，展示的是个人数据
   和记录列表，并没有"一次跑步的轨迹分享卡"这种形态。
2. **各个参数都要能改**——不能只有一两个数字可调，距离、时间、配速这类核心指标都得能编辑。
3. **背景跑步图要能换**——这是最关键的一条。原来的记录条目直接贴 `static/path/path1..7.png`，
   轨迹是"画死在图片里"的，换背景就等于换轨迹，两者无法解耦。

## 三、实现方案

### 关键决策：轨迹改成矢量绘制

如果沿用"贴一张带轨迹的现成图片"的做法，第 3 条需求根本没法好好满足——用户换了自己的照片，
照片上就没有轨迹了。所以这次把轨迹改成 **canvas 上按点序列矢量绘制**：

```
背景图（内置示意地图 / 纯色 / 相册照片）
        ↓ drawImage，cover 裁剪
轨迹描边（外层深色 casing + 内层白色 casing）
        ↓ quadratic/line 连接的折线，圆角端点
轨迹主线（用户选的颜色）
        ↓
起终点标记 → 顶部信息胶囊 → 底部数据卡 → 水印
```

这样背景换成任何照片，轨迹都还在、都清晰；轨迹形状也可以独立于背景随意换。
为了让轨迹在明暗底图上都能看清，主线上下各描一层边（深色 + 白色双层 casing）。

### 交互上的几个细节

- **所见即所得**：预览用的就是最终导出用的那块 canvas，不存在"预览和导出不一致"。
- **智能联动**：距离 / 用时 / 配速三选二自动推导第三个；步数 = 步频 × 时长；卡路里按 `1.036 × 体重 × 公里` 估算。
- **自动标记**：卡路里和步数默认自动计算，标签旁有「自动」角标；用户手动改过一次后角标消失，
  该字段不再被自动覆盖——既不会跟用户抢输入，又不会出现前后矛盾的数据。
- **输入宽容**：`32:15`、`32分15秒`、`5.5`、`5'30"`、`5.2公里` 都能识别，失焦时规整成规范写法。
- **参数持久化**：填过的内容存在本地，下次进来还在。

## 四、怎么验收

### 手动验证（HBuilderX）

1. 打开项目 → 运行到浏览器 / 手机
2. 首页点「轨迹截图」
3. 改「距离」→ 上方配速应立刻跟着变；改「配速」→ 用时跟着变
4. 「轨迹」里换形状与颜色 → 上方轨迹立刻变化
5. 「背景地图」左右滑动换图 → 底图变化，**轨迹仍然在**
6. 点「选照片」用一张自己的照片 → 底图变成照片，轨迹依然清晰
7. 点右上角「保存」→ App 端进相册；H5 端弹出大图，长按保存

### 自动验证（不需要 HBuilderX）

```bash
npm install
npm run verify     # 静态检查 + 41 项单元测试
npm run preview    # 生成排版预览图到 tools/out/，并自动体检排版
```

`npm run preview` 输出的是**真实绘制逻辑**渲染出来的图（文字用等宽色块代替字形，
方便检查对齐与溢出），可以直接肉眼确认排版，也能在 CI 里当回归基线。

测试覆盖到的不变式举例：

- 7 种轨迹 × 20 个 seed：所有点都在 `[0,1]` 内、无 `NaN`、同 seed 结果完全一致、相邻点距离不突变
- 轨迹映射到画布矩形后**不越界且居中**
- 布局常量自洽：胶囊 / 轨迹区 / 数据卡不重叠，三列数据不越界
- 绘制指令里不出现 `NaN`；缺失字段显示 `--` 而不是 `undefined`
- 状态联动：配速 × 距离 ≈ 用时；手动改过的字段不被自动覆盖
- 地图素材文件存在、路径合规、生成结果不是纯色

## 五、已知取舍与后续可做

- **内置地图是示意图形**，不是真实地图。刻意如此：不引入地图服务商依赖，也没有版权与配额问题，
  仓库里 6 张图合计只有 153 KB。想要更真实的效果，可以接静态地图服务，或让用户自己传截图。
- **相册自定义底图存的是临时路径**，重启 App 后可能失效。要长期保存可以像头像那样用 `uni.saveFile` 落盘。
- **导出分辨率是画布尺寸的 2 倍**（`destWidth` / `destHeight`），够发朋友圈；需要更高可以调这两个参数。
- 还可以继续做：轨迹可拖动/缩放、叠加心率曲线、导出多种比例（方形/竖版/横版）、
  保存多套模板、自定义水印文字。
